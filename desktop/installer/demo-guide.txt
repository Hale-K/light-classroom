轻课堂演示版安装与使用说明

1. 适用于 Windows 10（1607 或更新版本）/ Windows 11 的 64 位系统。
   无需安装 Python、Node.js、Docker 或数据库。
   系统缺少 WebView2 时，安装程序需要联网安装运行环境。

2. 安装后打开桌面上的“轻课堂演示版”。
   首次启动会将学校数据快照和可用附件复制到本机 SQLite，请稍候。

3. 教师端演示登录：账号 13710617058，密码 123456。
   学校：奶思兔咪鱿；用户：兔咪；身份：校长管理员。
   平台管理员登录：账号 admin，密码 admin123456。

4. 数据目录：%APPDATA%\LightClassroomDemo。
   演示版使用独立的本地数据库，与普通版分开安装和保存数据。
   重新启动及安装会保留你对演示数据的修改；卸载也会保留数据。
   演示版的修改不会同步到联网数据库。

5. 历史导出任务记录已保留；3 个早期文件的原件未能取得。
   其余可用导出文件随演示包提供。AI 服务商 API 密钥已清空，
   AI 功能需要自行配置模型服务并联网。

6. 导出保存对话框默认打开当前用户的 Downloads（下载）目录。
   启动日志：%APPDATA%\LightClassroomDemo\launcher.log。
