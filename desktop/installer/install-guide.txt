轻课堂安装与首次使用说明

1. 支持 Windows 10（1607 或更新版本）/ Windows 11 的 64 位系统。
   无需安装 Python、Node.js 或 Docker。

2. 按“下一步”选择安装位置，确认桌面快捷方式，然后点击“安装”。
   默认安装到当前用户目录，一般无需管理员权限。
   如果系统缺少 WebView2，安装程序会联网下载并安装，请保持网络连接。

3. 完成后启动轻课堂。首次启动会自动初始化数据库，请稍候。
   在登录页切换到“平台管理员”，账号：admin，密码：admin123456。
   登录后请修改默认密码，并配置学校及教师账号。

4. 默认使用本机数据，不会自动连接学校服务器或同步其他电脑的数据。
   教学数据和附件位于 %APPDATA%\LightClassroom。
   卸载程序会保留该数据目录。重新安装后可以继续使用原有数据。
   如果已有数据或 server.url 配置，启动时会继续使用。

5. AI 功能需要配置模型服务并联网；本机版不提供 MinIO 云端课件存储。
   如启动失败，可检查 %APPDATA%\LightClassroom\launcher.log。

本安装包为试用版本。
