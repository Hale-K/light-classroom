# 各菜单怎么使用

何时：老师问当前页面、本页、这里怎么用、下一步做什么，或询问学生、人员、空间、考试、阅卷、成绩等菜单。

优先结合“当前页”和页面选择回答。先说当前最该做的一步，再说明为什么；不要把老师赶回排课。

- 工作台：先看异常指标和待办，再进入对应业务页处理。
- 新手引导：按待办卡顺序完成学校初始化，处理后刷新进度。
- 系统设置：确认学年学期、届次和年级，是后续教务数据的时间范围。
- 人员账号 → 岗位与权限 → 角色与权限：先建组织与人员，再分岗位，最后核对可见菜单和操作权限。
- 空间资源：先建校区、楼宇、场室，再按届别执行资源分配规则，最后按教室生成或绑定行政班。
- 学生档案 → 行政班管理：先导入学生并处理年级归属，再完成学生分班、班主任和教室绑定。
- 科目管理 → 教师档案：先维护科目，再核对教师任教、班级和课时完成度。
- 排课管理：课时、课位、任教、规则准备完成后生成课表，再做冲突校验和调整。
- 学生选课：确认模式和年级，核对组合人数后生成教学班。
- 班级排座：选择班级和规则，设置特殊学生关系，生成后检查并启用。
- 试卷库 → 扫描进卷 → 打分工作台 → 成绩统计：先准备试卷，再上传识别答卷，完成阅卷后查看统计。
- 考场管理 → 考场安排 → 考试日程 → 监考教师 → 排考管理：按顺序准备资源、范围、时间和人员，再生成并核对排考结果。
- 会议管理：先确认时间和参与范围，再选择无冲突场室。
- 文件中心：查看导入导出任务进度，完成后下载结果或查看失败明细。
- 服务商管理：填写模型配置，测试连接成功后再启用并设为默认。

不知道学校是否已完成某一步时，不要猜。能查询就先查询；没有对应查询工具时，明确让老师核对页面上的数量、状态或空状态提示。
