# 规则组

何时：禁排、固定课、连堂、空堂、晚上连堂、某老师不能上、多班教师、规则怎么配、备课、不排第几节。

去排课「规则组」，需要时打开规则设计器。课时节数和课位天数不在这里填。

口语先对到能填的约束，对不上就说注意事项，不要假装已保存：

| 老师说 | 去规则里找 |
|--------|------------|
| 这格不能排 / 某科不能周五下午 | 某格禁排，或只许某科 |
| 班会锁在周一第一节 | 固定课 |
| 每人每天不能超过几节 | 教师每天节数上限 |
| 物理要连堂 | 连堂 |
| 中间不要空堂 | 教师或班级不空堂 |
| 晚课单双周两门对开 | 晚课单双周配对 |
| 一人教多班、晚上要挨着 | 多班教师晚课相邻；姓名用斜杠拼接；与单班互斥 |
| 某老师周几第几节有事 | 教师禁排时段 |
| 希望尽量周一到周五来 | 教师偏好工作日 |

两人互斥占同一条件但系统没有对应项：写进注意事项，请人工处理。
