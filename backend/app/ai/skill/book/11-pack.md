# 规则组件对照

何时：备课、备课时段、班主任晚课、对课、单双周、多班晚课、体育安排、这些规则、整包规则、规则怎么配。

说明书跨租户共用。禁止写某校教师姓名或某班钉位。对象从本校档案和班级勾选；对不上就停，不要编教师。
节数在课时管理填。第 8、9 节先对上课位晚课格。

编排：判断当前页 → 跳转按钮 → 建议组件类型 → 老师在规则组勾选并绑定本校对象后保存。

口语 → 组件（先硬后软）：

| 老师说 | 规则组件 |
|--------|----------|
| 各科某时段不排该科 | 课位禁排（学科 + 周几 + 节次） |
| 某晚必须班主任 | 指定课位必须班主任 |
| 班无空堂 / 教师每天最多 N 节 | 班级无空堂 + 工作日教师课节上限 |
| 某科有一天连堂 | 学科连堂（周课时在课时管理） |
| 某科只能若干课位 | 学科课位限制 |
| 某教师不排某节或某几天晚课 | 教师课位禁排 |
| 晚课日必须有某节 / 某几节至少 N 节 | 晚课日白天联动、节次下限 |
| 某教师要连堂、晚课只某天 | 教师连堂 + 晚课禁其它天 |
| 多班晚课轮转 | 多班教师晚课轮转 |
| 班主任不排某节 / 某节均衡 | 班主任禁该格 + 该节教师每周上限 |
| 某班某几节只许若干科 | 班级允许科目 |
| 固定某人某班某格 / 某班留自习日 | 固定课 + 班级晚自习日 |
| 晚课两科单双周对开 | 晚课单双周配对 |
| 尽量某几天来、体育上下午对开 | 教师日期偏好（软） |

系统没有的互斥（有第 2 节就不能有第 5 节等）写入注意事项，人工核对。
「科任不坐班」没有坐班实体，用无空堂近似。

工具：提到备课、对课、这些规则时打开规则组，按上表说组件名。由老师绑定本校教师/班级后保存。
