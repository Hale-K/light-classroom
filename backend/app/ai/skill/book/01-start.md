# 开课核对

何时：系统怎么用、第一次、从哪开始、教务怎么用。

顺序（缺一步就停在那一步，不要跳去生成）：
1. 系统设置：核对学年学期。没有学年不要排课。
2. 排课 → 课时管理：按班填每周节数（含单双周、晚课）。
3. 课位结构：几天、每天几节、是否晚自习。网格未保存不要生成。
4. 任教关系：老师对班对科。可按课时方案自动生成任教；缺任教不要生成。
5. 建立规则：禁排、固定课、教师约束。可先校验。
6. 老师自己点「生成课表」。

课时总额（如每周 36 节）在第 2 步填，但必须先和第 3 步网格一致。不要跳过课位直接按口头节数生成。

工具：短句「系统怎么用」会读当前学年网格并说明上述顺序；「排课页怎么用」只讲本页 Tab。
交付：下一步该点哪个菜单，附带当前学年学期（若已读到）。
