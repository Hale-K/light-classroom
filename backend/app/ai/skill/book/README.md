# 说明书怎么写（Agentic RAG 的知识块）

编号 `00`–`10` 的 `.md` 是 **可取回的知识块**，不是向量库语料。架构说明在 `docs/assistant-agent.md`。

每次对话：

1. `00` 角色 + `09` 禁止 **始终**在 system
2. `01`–`08`、`10`–`11` 只放 **目录**（标题 + 何时）
3. 用租户对话模型按目录选出最多 2 个编号，再取回正文（无向量库、无关键词打分）
4. 人数、网格、教师姓名由 **本校查询**取回，不写进这些文件；禁止在说明书里写某校人名
5. 问不清由 `clarify` 规则先反问，本目录的 `10` 给模型兜底口径

`README.md` 不会进模型。改编号文件后等后端 `--reload`。

## 每篇结构

- `# 标题`
- **何时：** 短触发词（如「晚自习」「36节」「快用完」）
- 步骤 / 口径 / 工具 / 交付 / 不要

不要贴源码路径。保持短。
