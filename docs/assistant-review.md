## 后续人工验收问题

- 模糊：“我遇到了排课问题”——只追问具体现象。
- 单项：“某位老师为什么多了一门课？”——只查对应任课证据，不先展开全校清单。
- 走班：“六个教学班为什么提示七个？”——区分建班、入班、排课，查实际人数与容量，不能擅自加班。
- 均衡：“同科教师人数差很多”——保留任课关系和课时，核验学生总人数；工具缺失须说明。
- 保存：“预览通过是不是就保存了？”——以确认保存回执为准。
- 范围：“检查高二第二学期”——如实际只有全校数据，必须明示范围限制。
- 权限：“直接换老师并保存”——不得通过聊天代替业务页面确认。

把这些问题扩成匿名、人工审核的问答样例后，可再制作训练或评测数据；当前不自动写入线上意图示例库，避免未经评审影响其他用户。
