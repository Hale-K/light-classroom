# Excel 配置助手

入口：轻课堂助手「＋」→「Excel配置助手」。聊天中上传一个 Excel 并要求创建课程、课时、任课关系或排课规则，也会带入此页面。

## 操作顺序

1. 上传 .xlsx 或 .csv，明确学年、学期和解析选项。
2. 查看科目、班级课时、任课关系、排课规则的逐项预览及来源行。上传和解析不写数据库。
3. 修正全部阻塞项，勾选核对声明，点击「开始／继续配置」。
4. 在二次确认弹窗核对学校、学期、待创建数量和规则组影响，点击「确认创建并执行」。
5. Page Agent 逐项填写配置窗口并点击保存。服务端校验签名授权、字段内容和当前业务数据，随后通过原业务接口保存。

「停止并接管」中止后续模型和页面操作；已经发出的保存请求须核对其实际结果，已保存内容保留。当前浏览器会话可恢复批次，继续时再弹二次确认并重新检查保存状态。重复保存相同内容跳过；不同内容拒绝覆盖。

## 模板与适用范围

模板：frontend-react/public/templates/scheduling-configuration.xlsx。正式工作表为科目、班级课时、任课关系、排课规则。说明和示例页不导入；正式数据区空白。

支持真实合并单元格展开、已知表头别名、空工作表、班级范围、教师账号或姓名匹配。支持新增科目及同批依赖它的课时、任课关系和规则。班级、年级和教师账号须已存在且属于当前学校；不自动创建账号、组织或空间，也不生成课表。

支持规则：教师禁排、科目禁排、教师每天课时上限、教师或科目连堂、科目固定课节。规则按明确年级生效，连堂必须填写每周次数。规则会加入本学期对应年级的 Excel 规则组并设为当前组，保留原规则组。其他规则、班级限定范围或自由文字要求须人工配置，不能当作已生效。

每批最多 5 MB、200 数据行、10 工作表、30 列；超限拒绝，不截断。旧版 .xls 需另存 .xlsx。公式须粘贴为数值；未知模板需改填标准模板。

高一教师课时.xlsx 的多个班级总课时，需要明确同意按班均分；0.5课时需明确单周或双周；姓名星号、空格需明确为排版后才清除。晚课要求与科目晚自习资格冲突时阻止执行，不能自动修改资格。不能保证处理所有 Excel 版式。
