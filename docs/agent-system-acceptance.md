# Agent 系统验收

日期：2026-10-09（原始环境建立于2026-10-08）。目标是检查真实页面、真实模型、真实数据库查询链路，并验收两类语义和复杂任务的时间上限。测试问题与预期先确定，不以回答看起来合理作为通过依据。

## 环境与基准

独立本地前端5179、后端8004、PostgreSQL合成验收库；普通教师另用5181前端隔离登录会话。相同应用代码和已配置实际模型，两个租户分别是行政班与走班模式，当前2026-2027第二学期、高一与高二。旧学期设置另有保存课表。测试账号只访问合成学校。

每校6位高一学生：3人有选科（确认1、草稿1、锁定1），3人未选科，1人未分行政班；两名同名学生、两名同名教师。学生甲物理重复入两个教学班，学生乙选科草稿且未入班，学生丙历史已入班。行政模式保留同样走班遗留记录以验证不会误读。

高一两班，任课3条（高一1班数学任课记录9节、方案单周5/双周4，语文6；高一2班数学4），高二数学4。甲老师跨高一、高二任教。周一第1节有已知跨班、跨年级和跨行政/走班的共享教师冲突；第2节单周、双周课程互不冲突。当前高一保存行政课5条，走班课3条。学生甲当前行政课4条，合并走班共6条，旧学期只有旧班周一第4节1条。当前白天课位为每周5天×8节=40，不能套用54。

## 两类语义与运行契约

页面只使用“普通问答/查询”和“复杂规划/执行”两种语义标签。行政班/走班属于学校环境；已有“只读计划模式”属于用户对写入的限制，均不新增执行语义。复杂规划标签不授予数据库写权限；明确执行请求仍需工具授权、变更确认和回读验证。

复杂任务整轮最多600秒，每次循环的模型请求、工具调用与结果修复共同受120秒上限约束。单轮超过120秒应保留已取得的事实，报告实际超时步骤；备用模型和HTTP重试不能无限重置预算。前端轮询可观察610秒，留下终态传输余量。刷新、重连只查看同一任务，不重新提交。完成后立即交付，不要求任务必须运行满10分钟。

“100%识别”的验收口径是指定独立语料全部通过，并保留误判回归样本；不能以有限样本声称任意自然语言永远正确。

### 复杂课时方案的可核算基准

原题固定课时为体育2、音乐1、心理1，共4节；周一至五第1—7节必满为35节。在每天8节的合成环境，三套可实施方案可取35、38、40节，文化课分别31、34、36节；分项必须等于总量，晚课与周六不能偷偷补入。允许不同分配，不强制模型复述固定答案。第9节当前不存在，45节方案应被程序识别为超容量。

数字合计正确不等于整张课表已可排：教师工作量、资源碰撞和单双周仍须各自查证；未调用实际排课求解器时不能保证所有规则满足。
