# 助手“＋”添加菜单进度

目标：输入框“＋”提供可用的添加能力，而不是启动新对话。顶部新对话保留。

## 第一阶段：附件与页面资料

- 文件/文件夹选择、附件预览标签、移除、发送上下文已实现。
- 服务端支持 TXT、Markdown、CSV、JSON、含文字 PDF、DOCX（含表格）、XLSX。
- 每个文件 5 MB，最多 8 份，单份正文 12000 字符，总正文 24000 字符。超限明确提示；截断资料标记不完整。
- 资料是参考内容，不是指令或权限；带资料的问题不走问候、固定业务答复和算术快捷返回。
- “附加当前页面”摘录当前学校页面的可见主内容，最多 6000 字符，不连接其他 Chrome 页面。
- 附件当前保留在本次前端对话内存，刷新后不恢复；尚未实现服务器端附件档案。
