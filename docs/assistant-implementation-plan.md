# 排课 Agent 第一版

范围：复用现有模型工具循环、规则引擎和助手面板，完成规则查询、草稿、确认保存的闭环。

1. 规则草稿服务：按本校真实科目/教师名称解析目标，支持白天科目禁排、教师禁排、学科连堂、教师每日上限；校验网格、参数和规则组，保存有期限的待确认草稿。验收：生成草稿不改变规则目录；未知/歧义对象被拒绝。
2. 确认接口：草稿绑定学校与发起人；确认时锁定草稿和规则目录、检查快照、原子追加并记录审计；取消、过期和重复请求有确定结果。验收：跨校/跨用户不可操作，重复确认只写一次，旧快照不覆盖新修改。
3. Agent 接入：模型通过工具生成草稿；自然语言查询和多轮补充走后端，前端显示可信草稿和确认/取消操作。验收：查询不误入规则操作指导，补充星期能继承上文，模型不能直接执行写入。
4. 验证与文档：后端数据库事务测试、工具循环测试、前端类型检查/构建和可用的浏览器验证。记录真实模型和数据库环境的验证边界。

暂不代点生成课表；规则保存后老师仍在排课页发起求解。第一版不支持的规则给出操作指导，不伪装已保存。既有课时预览保留。
