# 排课准备流程

助手与新手引导共用准备状态。按下表顺序推荐第一个未完成项，不根据回答中出现“规则”等词语选择跳转。

| 顺序 | 准备内容 | 页面 |
| --- | --- | --- |
| 1 | 设置当前学年、学期 | 系统设置 `/settings` |
| 2 | 添加教师，启用账号并解除冻结 | 人员账号 `/staff` |
| 3 | 建立校区、楼宇、场室 | 空间资源 `/campus-buildings?tab=resources` |
| 4 | 将教室分配给当前学期的届别 | 届别资源分配 `/campus-buildings?tab=allocation` |
| 5 | 建立当前届别的行政班并关联已分配教室 | 班级划分 `/campus-buildings?tab=class-planning` |
| 6 | 设置上课日、节次等课位结构 | 排课·课位结构 `/scheduling?tab=slots` |
| 7 | 配置班级课时方案 | 排课·课时管理 `/scheduling?tab=hours` |
| 8 | 配置当前班级的教师任教关系 | 排课·任教关系 `/scheduling?tab=assignments` |
| 9 | 按需配置额外排课规则 | 排课·规则 `/scheduling?tab=rules` |
| 10 | 生成课表并检查冲突 | 排课·课表 `/scheduling` |

这是推荐办理顺序，用户仍可以分别维护基础数据。前八项有缺项时，助手展示准备清单与第一个缺项的入口，暂不执行后续排课细项诊断。额外排课规则用于表达教师或班级的特殊要求，属于按需配置，不是开始排课的前置条件。

“已有基础记录”不等于完整校验通过。教师人数只统计具有本校“任教老师”角色、启用且未冻结的账号；普通人员的基础角色相同，但不会计入教师准备。空间记录只计入当前启用校区内状态为 available 且允许排课的场室；存在场室仍不等于空间容量足够。存在教师不等于各科任教覆盖完整，班级存在任教记录不等于全部课时已匹配。教师超负荷、规则相容性和求解可行性仍需进一步检查。当前人员检查针对教师，不包含学生档案完整性。生成步骤依据当前学年学期班级的实际课表条目；历史版本只是覆盖旧课表时保存的可恢复快照。

历史对话保留原结果；修复后的流程在重新发起排课准备检查时生效。
