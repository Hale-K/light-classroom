# 教务助手两类语义与长任务执行规格

用户确认的入口为普通问答/查询（query）和复杂规划/执行（planning）。行政班/走班、学年学期、年级属于工具核实的业务环境，不能成为新的语义模式。

## 行为与边界

- 普通问候、解释、单项查询走 query；多方案、连续取证与诊断、全面审计、执行请求走 planning。承接方案修改要参考最近对话；低置信度或指代不清先澄清。有限验收语料全部通过不等于开放语言百分之百识别。
- 复杂任务先列可更新的步骤，再取证、计算、校验、总结。仅按实际完成情况标记步骤；缺配置可标记阻塞，不得冒充完成。
- 每个完整循环最多 120 秒，包含模型、故障转移、工具及答案修复。整个任务最多 600 秒；取消或超时必须停止底层工作。备用模型继续同一上下文，不重新运行已完成的取证。
- 语义模式不授予写权限。计划模式的既有只读锁继续有效；规则草稿仍需独立确认接口才能写入；任课关系和用户课时不能擅改。
- 方案必须读取所选年级学期真实课位，处理单双周与停用课位。三方案使用程序计算分项和合计、必排下限、实际容量及固定课程；校验课量不能声称整体排课可行。
- 高考选科规则与分值/课时权重分开。缺少权重来源明确说明，并标明假设或询问；不能把高一全科与最终六科混为一谈。
- 数字对比使用可读表格，给出范围、来源及缺失项。

## 实施范围

保留现有 Runtime、ModelGateway、ToolGateway、ReactLoop、AiRun。替换五类标签绑定工具限制的交互路由，不引入外部框架。增加本轮计划工具、年级规划依据工具、方案验算工具。计划进度进入已有事件与检查点；页面仅展示两种语义入口及实际步骤。

## 验收

自动回归：两类语义（含多轮、问候前缀、只读复杂任务）、年级课位来源、单双周、容量/固定课时、租户与真实身份权限、循环和总任务截止、故障转移保留证据、取消与重连。

页面使用隔离合成学校与真实配置模型：行政与走班环境、分页与历史、权限拒绝、截图原题三方案、停止/进度及数字表格。交付实际截图和已执行的验收记录，未执行项目明确列出。

运行后端定向 pytest 和前端类型/构建及活动投影测试；保持已有工作区修改，不更改实际学校业务数据。
