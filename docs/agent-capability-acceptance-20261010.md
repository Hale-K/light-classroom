# Agent 能力验收（2026-10-10）

## 验收结论与边界

本轮覆盖相近问法路由、环境与缺项澄清、单双周师资验算，以及新增排考查询工具。没有据此宣称所有复杂任务都可完整执行，或自然语言识别达到100%。

## 发现并修复

- 原本仅部分带阿拉伯数字和特定措辞的问题进入复杂规划；中文数字、资源协调及多轮重算容易进入普通查询。补充业务结构识别，并保持简单查询独立。
- 真实语义分类器会把部分明确查询错判为规划。明确查询优先走本地规则；不确定表达仍使用语义分类及澄清。
- 模糊请求先展示待确认计划，询问目标和范围；环境信息由工具核实，不能从页面猜测。
- 页面多轮调整曾跳过计算工具，并将全20班单周心理课按周均课时计算为1位教师。增加单双周峰值计算；单周20节、每位14节需至少2位，周均10节不代表1位能覆盖单周需求。
- 师资方案数字回答增加必须调用程序计算的检查，不能只复用历史结论。

## 排考新增能力

`lookup_exam_operations`：本校考试列表、配置概况、日程、考场安排、监考工作量与可用配置、考生座位分页、真实冲突检查。列表之外必须明确考试ID或名称；明确学年学期需匹配，不能代选考试。查询沿用服务端教务管理权限。

`calculate_exam_capacity`：按同场去重参考人数、规则后可用座位、每间监考人数计算峰值需求。例如同场1000人、每间30座、2位监考，至少34间考场、68位同时监考人员。这不是整场考试的去重教师数，也不是完整编排可行性验证。

排考环境区分全员/选科参考、自定义/学校日程策略、考场座位规则；不能套用课表行政班/走班模式。检查器复用排考页面业务逻辑，检查容量、重复座位、考生与教师重叠、跨考试冲突、可用时段、工作量及规则。

当前新增工具只读，不生成、调整、保存或打印考试安排。排考写操作尚未接入Agent确认链路。
